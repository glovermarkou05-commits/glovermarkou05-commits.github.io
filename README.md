# MG Digital Solutions · Sitio corporativo V5

Sitio estático publicado por GitHub Pages. Conserva el estilo corporativo aprobado y presenta los productos de MG Digital Solutions.

## Páginas

- `index.html` — inicio, portafolio y Nosotros con misión, visión y valores.
- `ventry.html` — catálogo de Ventry Commercial, con alcance por versión.
- `mg-club-plus.html` — MG CLUB+ y los 14 módulos descritos.
- `finzy.html` — FINZY y su estado de pruebas Android QA.
- `.nojekyll` — publicación directa de archivos estáticos.

Los formularios que ofrecen WhatsApp preparan un mensaje y requieren que el visitante lo envíe; GitHub Pages no guarda información ni ofrece backend.

## Publicación

Settings → Pages → Deploy from a branch → main → / (root).

## Precisión comercial

- La versión local Windows de Ventry se describe de manera distinta a la sincronización entre dispositivos.
- No anunciar emisión electrónica autorizada por el SRI sin completar las verificaciones correspondientes.
- No enlazar a Google Play ni generar QR para FINZY hasta confirmar su ficha pública oficial.
- Las exportaciones PDF/Excel y funcionalidades en QA se anuncian solo si se validan en la versión comercial.
- Los resultados ilustrativos no constituyen datos de clientes.
