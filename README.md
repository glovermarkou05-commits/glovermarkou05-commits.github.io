# MG Digital Solutions · Sitio V4

Sitio corporativo de MG Digital Solutions y presentación de Ventry Commercial.

- `index.html`: página principal.
- `ventry.html`: presentación de Ventry Commercial.
- `.nojekyll`: publicación directa de archivos estáticos.

Los formularios abren WhatsApp con un mensaje preparado; la persona debe pulsar Enviar desde WhatsApp. No existe almacenamiento de solicitudes en GitHub Pages.

Para publicar: Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.
