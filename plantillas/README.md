# MG Web Studio — Plantillas

Prototipo interno para revisión. Plantilla demostrativa en plantillas/web-emprendedores/index.html.

Cada cliente necesita sitio, repositorio, dominio y datos independientes. Sustituir nombre, contenidos, fotografías, metadatos y contactos; probar enlaces y diseño móvil. Nunca duplicar secretos ni datos reales de otros clientes.

La versión visual actual no incluye inicio de sesión, CMS, carga autónoma de promociones, almacenamiento ni panel administrativo. Para vender una modalidad de autogestión, primero diseñar autenticación, permisos, CMS, almacenamiento y aislamiento por cliente.
